# Assertions: memory management

Source: NOLX M3 -- the memory-manager contract in `docs/architecture/03-memory-manager.md`
and the invariant set in `crates/nolx-mm-core`. Rows marked `tested-T1` are exercised by
`cargo test` on the host; rows marked `pending-T2` are asserted by the QEMU boot smoke test
in `.github/workflows/ci.yml` and are promoted to `tested-T2` only once a workflow run on
this revision has passed.

The split matters here more than anywhere else. Every algorithm in the memory manager --
splitting, coalescing, the VAD tree's balance, the heap's boundary tags -- lives in
`crates/nolx-mm-core`, which has no hardware dependency and `forbid(unsafe_code)`. The
kernel keeps only the parts that must touch a machine: the frame map, and the `BlockStore`
implementation that reads and writes free-list links through the direct map. A `tested-T1`
row therefore covers the same code the kernel runs, not a re-implementation of it.

MM-029 | Page tables in the kernel: per-process address spaces are built over frames from the allocator | pending-T2 | `AddressSpace::create_in_place` takes a zeroed PML4 from the frame allocator, marks it a page table, charges the system PTE pool, and shares the kernel half of the address space by copying the running root's PML4 entries from slot 256 up; everything below that is allocated and reclaimed by kernel/src/mm/tables.rs `KernelTableStore`, whose `release_table` returns an empty table to the frame allocator and releases its pool charge. The space is built *in place*, one field at a time, and torn down through a borrow: a value of the type is tens of kilobytes -- the boot self test found a stack overflow that had been silently writing past the kernel stack -- so nothing may move one through a function boundary. Teardown unmaps every range, frees the child tables the unmaps emptied, and frees the PML4. The boot self test proves the accounting closes: the page-table allocate/release counters move by the same amount across the test and the free-frame count returns to exactly its pre-test value, which is the `free frames A -> A; page tables allocated X -> Y, released X -> Y` part of the boot smoke's address-space assertion. Promoted to tested-T2 when a workflow run on this revision passes
