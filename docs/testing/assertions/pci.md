# Assertions: PCI configuration space and device discovery

Source: NOLX M9 -- `ROADMAP.md` (Devices and drivers) and `crates/nolx-pci-core`. This file
covers legacy configuration-space access, function discovery, BAR decoding and sizing,
capability walking, bridge-aware bus enumeration, and validated MCFG/ECAM read-only access. The kernel binds the logic to
ports `0xCF8`/`0xCFC` (`kernel/src/hal/pci.rs`) and prints the inventory at boot. No row is
claimed as `tested-T2` until a CI boot run has asserted its marker. PCI-001 to PCI-008 are
`tested-T1`: the host tests passed in CI (workflow 38370090989, host-test job).

Rows are pipe-delimited: `ID | specification reference | status | test`.
