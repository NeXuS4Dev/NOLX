# Assertions: object manager

Source: NOLX M4 -- `docs/architecture/01-kernel-model.md` section 3 (Object Manager) and the rules
in `crates/nolx-obj-core` (handle tables, namespace). Rows marked `tested-T1` are exercised by
`cargo test` on the host; rows marked `pending-T2` are asserted by the QEMU boot smoke test in
`.github/workflows/ci.yml` and are promoted to `tested-T2` only once a workflow run on this
revision has passed.

All fourteen M4 rows are recorded as verified as of 2026-10-12: the nine host rows run in the
`Host tests (cargo test)` job, and the five boot rows (OBJ-006, OBJ-010 to OBJ-013) were promoted
on workflow run 38249363821 (revision 15aee68), whose QEMU boot smoke test greps for each of their
markers and fails the job if any is missing or if the run contains a `PANIC`, `BUGCHECK`, or
`CPU exception` line. No `pending-T2` row is left in this area.

OBJ-001 | Handle values are generation-checked: a handle to a closed entry never names the entry that reuses its slot | tested-T1 | `crates/nolx-obj-core/src/handle.rs` tests `closed_handle_is_stale_after_slot_reuse` and `generation_wraps_without_reaching_zero`.
OBJ-002 | DuplicateHandle may narrow access but never widen it, and a refused duplicate inserts nothing | tested-T1 | `handle.rs` test `duplicate_may_narrow_but_not_widen`.
OBJ-003 | Inheritance copies only inheritable entries and keeps the parent's handle values where the child's slot is free | tested-T1 | `handle.rs` tests `inheritance_copies_only_inheritable_entries` and `inheritance_falls_back_when_the_slot_is_taken`.
OBJ-004 | Namespace lookup is case-sensitive, rejects malformed paths, and follows symbolic links with a loop limit | tested-T1 | `crates/nolx-obj-core/src/namespace.rs` tests, including `symlink_cycle_is_a_loop_not_a_hang`.
OBJ-005 | Removing a directory with children is refused; removing a link removes the link, not its target | tested-T1 | `namespace.rs` tests `remove_refuses_nonempty_directory_then_allows_empty` and `remove_takes_the_link_not_its_target`.
OBJ-006 | An object's references follow the rules: a handle implies a pointer reference, and the object is freed exactly when the last reference goes | tested-T2 | `kernel/src/obj/boot.rs` `selftest` drives one object through (1,0) -> (2,1) -> (3,2) -> (2,1) -> (1,1) -> freed, checks each step, and requires the live count to return to its start; the printed report is `NOLX: obj selftest: 1 object, 2 handles (1 duplicated, 1 widening refused), 1 symlink lookup, refcount (1,0) -> (2,1) -> (3,2) -> (2,1) -> (1,1) -> freed, live objects 0 -> 0; audit ok`, asserted by the boot smoke marker `NOLX: obj selftest: 1 object, 2 handles` (CI run 38249363821, revision 15aee68, boot smoke green; first green on 38133425376, revision 35728d3).
OBJ-007 | SeAccessCheck: a deny entry written before an allow refuses the rights it covers; the owner holds READ_CONTROL and WRITE_DAC implicitly; group membership and the everyone principal match; a null DACL grants and an empty DACL denies | tested-T1 | `crates/nolx-obj-core/src/security.rs` tests `deny_written_before_allow_wins_for_the_same_principal`, `owner_holds_read_control_and_write_dac_implicitly_but_not_read`, `group_membership_is_matched_through_the_token`, and `null_dacl_grants_everything_and_empty_dacl_denies_everything`.
OBJ-008 | Mandatory integrity labels refuse write-class rights to a lower token but not reads; BACKUP grants reads and RESTORE grants writes only where the DACL has not refused them | tested-T1 | `security.rs` tests `integrity_label_refuses_write_class_to_a_lower_token`, `backup_privilege_reads_what_the_dacl_does_not_grant`, and `restore_privilege_writes_but_does_not_override_a_deny`.
OBJ-009 | Every access decision made through `open` is recorded, and the audit totals stay exact after the bounded log wraps | tested-T1 | `security.rs` test `audit_log_keeps_exact_totals_past_its_capacity`; at boot the self test requires the audit delta to equal every call that reaches the SRM, including lifecycle opens.
OBJ-010 | At boot, `open` enforces the monitor's decisions for a SYSTEM, reader, refused, backup, and low-integrity token against a device and a labelled log, and the audit log agrees with what was asked | tested-T2 | `kernel/src/obj/boot.rs` `selftest`, part two: ten access cases through `open`, the audit delta required to equal the decisions, and the refusal total required to equal the cases that deny; any disagreement fails the boot with a panic. Boot marker `NOLX: srm selftest: 10 access checks (6 granted, 4 denied)` (CI run 38249363821, revision 15aee68, boot smoke green).
OBJ-011 | Object type create/open/parse/close/delete callbacks run at their lifecycle transitions; a type-rejected create or open leaves no header, handle, or reference leak | tested-T2 | `kernel/src/obj/mod.rs` registers the Device callbacks and `kernel/src/obj/boot.rs` dispatches them; the selftest forces create/open rejection, checks rollback (no slot, no handle, counts back to (1,0)), and requires every callback count to advance. Boot marker `NOLX: obj type callback selftest: create/open/parse/close/delete invoked` (CI run 38249363821, revision 15aee68, boot smoke green).
OBJ-012 | Session directories are initialized under `\\Sessions\\<id>` and the same child name in two sessions resolves to distinct objects | tested-T2 | `kernel/src/obj/boot.rs` selftest creates `SharedName` in sessions 0 and 1 and checks distinct ids and lookups, then requires the header pool back where it started. Boot marker `NOLX: obj session selftest: sessions 0 and 1 are isolated` (CI run 38249363821, revision 15aee68, boot smoke green).
OBJ-013 | Private namespaces isolate identical paths, enforce boundary READ/WRITE/DELETE checks, audit allowed and refused operations, reject destruction while nonempty, and invalidate stale ids after slot reuse | tested-T2 | `kernel/src/obj/boot.rs` selftest creates same-path objects in two roots, follows a private link, opens through it, checks one outsider denial and an exact audit delta (15 decisions, 1 refused), cleans up objects/directories, and verifies stale-generation rejection and nonempty destroy refusal. Boot marker `NOLX: obj private namespace selftest: boundaries enforced, isolated roots` (CI run 38249363821, revision 15aee68, boot smoke green).
OBJ-014 | The generic private namespace primitive gates reads, writes, deletes, and symlink creation with its boundary descriptor while preserving symlink resolution within its independent root | tested-T1 | `crates/nolx-obj-core/src/namespace.rs` tests `private_namespaces_are_isolated_for_the_same_path`, `private_namespace_symbolic_links_stay_inside_their_root`, and `private_namespace_boundary_gates_read_write_and_delete`.
