# Assertions: kernel input objects and independent subscriptions

Source: M9 bounded input event objects. This API is kernel-facing, not an Executive object
namespace, process handle table, waitable syscall or POSIX input-device binding. Pure contracts
live in `nolx-input-core::objects`; producers and synchronized API live in `hal::input`.
