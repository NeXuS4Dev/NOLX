# Assertions: kernel input objects and independent subscriptions

Source: M9 bounded input event objects and the POSIX descriptor on top of them. Pure contracts
live in `nolx-input-core::objects` and `nolx-input-core::wire`; producers and the synchronized
API live in `hal::input`; the Executive binding in `hal::input::executive`; `open`/`read`/`close`
over those objects in `kernel/src/exec/user/input.rs`. INP-001..INP-005 are the kernel-facing
objects, INP-006..INP-009 the user-facing path and device identity, and INP-010..INP-012 the
blocking `poll(2)` gate on top of them.
